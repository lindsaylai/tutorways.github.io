which allows you to specify a condition that the rows
must meet.

For example, to keep only rows where a column is
greater than a certain value, you would write:

  filtered_table = my_table.where("column_name", are.above(value))

You filter a table with tbl.where(column, condition). It keeps only the rows where that column meets the condition, like are.above(10) or are.equal_to('PG'). If you leave out are and just pass a value, it matches that value exactly.

How the benchmark works How evaluation is scored

Ferret grades understanding, not just answers.

Ferret is a framework for building mastery-based assignments. An AI grader questions students about their work until they've shown what they know.

Ferret on GitHub
  1. 1

    The code passes the tests.

    Passing tests don't show whether the student understands the code. Ferret starts there.

  2. 2

    Ferret asks about a case the tests missed.

    It picks an input the code doesn't handle and asks the student what happens.

  3. 3

    The student explains.

    They don't rewrite anything yet. They say what goes wrong and why.

  4. 4

    Ferret asks what should happen instead.

    The student knows the code crashes. Now they have to decide what the right behavior is.

  5. 5

    Ferret marks the concept and moves on.

    Once the student has explained the edge case, it counts as shown.
